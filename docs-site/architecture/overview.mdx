# Architecture Overview

NodalMerge is built around a distributed state graph.

---

## System Model

Each node maintains:

- Local state projection
- Append-only transaction log
- Deterministic merge engine

---

## Core Layers

### 1. Operation Layer
- Map / Text / List CRDT ops
- Lamport timestamp ordering

### 2. Transaction Layer
- Groups operations into signed transactions
- Content-addressed via hash

### 3. Graph Layer
- DAG of SyncNodes
- Enables replay, fork, and reconciliation

### 4. Sync Layer
- Incremental diff exchange
- Bloom / MST / IBF acceleration

---

## Design Principle

> Never reconcile state directly — reconcile history.

---

## Why this matters

This allows:
- replayable systems
- forkable timelines
- deterministic multi-writer convergence
