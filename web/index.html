⚡ Conflict Lab

Phase 4
  1. Open this page in two tabs.
  2. In each tab, click Go Offline.
  3. In Tab A click Set color=red; in Tab B click Set color=blue.
  4. In both tabs click Come Online.
  5. Both tabs converge on the same winner — the HLC timestamp decides.
