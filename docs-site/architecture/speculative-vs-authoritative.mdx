# Speculative vs Authoritative Execution

NodalMerge separates collaborative execution into two conceptual lanes:

- Speculative execution
- Authoritative execution

This enables responsive local-first experiences without sacrificing deterministic validation.

## Speculative lane

Clients apply operations immediately.

Benefits:

- Low latency UX
- Offline operation
- Reduced coordination delay
- Fast collaborative editing

Speculative state represents the client's current best-known projection.

## Authoritative lane

Authoritative systems validate canonical room state.

Responsibilities may include:

- Policy enforcement
- Signature verification
- Replay validation
- Governance rules
